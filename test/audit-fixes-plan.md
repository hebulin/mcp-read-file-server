# 2026-10-08 审查修复验收计划

所有实际文件样本、配置、外部进程辅助文件和日志使用项目 `.agent-tmp/` 下的隔离目录，禁止触碰用户真实 profile。测试使用现有 Node 内置运行器及 MCP SDK，不安装依赖。

1. 新路径写入在策略失败、暂存失败和部分 mkdir 失败时，核对真实目录与 changed/createdDirectories 一致；保留并发加入的内容。
2. 外部复制、目录探测、配置保存和安全中转同时发生主失败/清理失败时，原错误与残留路径都可见；成功清理告警不使已完成写入被当作失败。
3. 正则扩大输出在工作线程内拒绝超过 16MB；UTF8 多字节边界、零宽匹配、数字/命名捕获组、$$/$&/前后文标记对照原生 replace；失败后原文件字节保持不变，线程可继续工作。
4. 4096 字符且含大量正则元字符的 literal 搜索通过；真实 stdio 输入/输出 schema 验证不变。
5. 复制/移动现有空目录也计入一万项预算；目录深度上限128；边界模型与实际小目录合并均验证。
6. glob 空分支、嵌套空分支、已有模式语义和累计预算保持正确。
7. 排队取消/超时仅结束对应任务；运行任务取消/超时后其他任务继续；全局 stop 仍取消全部，队列容量保持16。
8. MCP错误保留 reasons、matched、createdDirectories 与 cleanupErrors，保持输出schema和实际changed一致。
9. 执行新增专项、全套 npm test、npm run check、依赖审计及发布清单 dry-run；记录实际平台/Node版本、通过/失败/跳过数与限制。

真实TSD驱动、不同物理卷和断电/进程强杀恢复不以模拟测试冒充现场通过；如本机缺少对应环境，列入明确的手动验收步骤。
